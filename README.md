# VybeOS
Buka index.html atau downloads.html langsung di browser. Tidak memerlukan instalasi atau build.
File: index.html (halaman utama), downloads.html (halaman download), styles.css (tampilan bersama), downloads.css (tampilan download), script.js (navigasi halaman utama), assets/ (aset Figma).
Font Google memerlukan internet; font cadangan digunakan saat offline.
Semua tautan Downloads dan tombol download di halaman utama menuju downloads.html.
Tombol ISO nonaktif dengan status Coming Soon sesuai desain. Versi dan ukuran berstatus TBA.
Desain home: https://www.figma.com/design/qY4UeVRUlJvYaDs90MMz4M/PROTOTYPE-WEB-SO?node-id=22-372
Desain download: https://www.figma.com/design/qY4UeVRUlJvYaDs90MMz4M/PROTOTYPE-WEB-SO?node-id=22-113

Halaman About: buka about.html atau menu About di Home dan Downloads.
about.css berisi tampilan khusus About; styles.css digunakan bersama.
Desain About: https://www.figma.com/design/qY4UeVRUlJvYaDs90MMz4M/PROTOTYPE-WEB-SO?node-id=17-476

Revisi konten: bahasa disederhanakan sesuai konteks proyek mata kuliah Sistem Operasi.
Spesifikasi perangkat merupakan target awal, bukan hasil pengujian.
Pratinjau terminal merupakan ilustrasi. Versi kernel dan pemakaian RAM menunggu data aktual.
Nama dan NPM tetap mengikuti data yang diberikan; istilah peran disederhanakan tanpa mengubah urutan anggota.
