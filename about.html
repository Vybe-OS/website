About VybeOS

Learning Linux by building our own setup.

VybeOS is our Operating Systems course project. We use Arch Linux to explore system configuration and put together a desktop for learning and programming.

Overview

What is VybeOS?

We are building an Arch-based Linux setup with Sway, Waybar, and development tools. The project gives us practice configuring a system and documenting how it works.

Our Vision

A Linux desktop that helps us learn how an operating system is configured and supports our programming assignments.

Our Mission

Configure the desktop, choose the tools we need, test the setup, and document the steps so others can try it.

Our Technology

The main tools selected for this project.

Arch Linux

The Linux distribution used as our starting point.

Sway

Arranges application windows in a tiled layout.

Waybar

Displays workspaces and system information.

Git

Tracks changes to our project files.
