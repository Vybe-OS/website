Installation Guide

The planned installation process.
Detailed instructions will accompany the ISO release.

  1. 01

    Download ISO

    Download the VybeOS Arctic ISO here once the release is available.

  2. 02

    Create Bootable USB

    Write the ISO to a USB drive with an imaging tool. This erases the USB contents.

  3. 03

    Boot VybeOS

    Restart your computer and select the USB drive from the boot menu.

  4. 04

    Install VybeOS

    Follow the installation guide provided with the release.
