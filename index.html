Why VybeOS?

We are building an Arch-based desktop for learning Linux,
writing code, and working with the terminal.

Arch Linux Based

Uses Arch Linux as a starting point for learning package management and configuring a Linux system.

Lightweight Desktop

Uses Sway to arrange application windows in tiles, with a simple desktop layout and keyboard shortcuts.

Developer Focused

Brings together a terminal, editor, and development tools for practicing programming and working on projects.
